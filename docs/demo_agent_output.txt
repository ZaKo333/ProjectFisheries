==============================================================================
ProjectFisheries —— 水产养殖智能监测与决策 Agent
链路：LLM 决策工具 → 工具执行 → 护栏校验 → 确定性融合 → RAG 定向检索 → 建议生成
==============================================================================
调度角色后端：scheduler: MockLLM（确定性离线模式）
建议角色后端：advisor: MockLLM（确定性离线模式）

==============================================================================
【演示说明】图像识别模型尚未训练完成，`fish_disease_detect` 走 mock 兜底。
本 demo 显式传入 mock_source="folder_hint"，让 mock 从图片所在文件夹名取标签
（底层 7 分类英文名 → 映射到 烂鳃/出血/水霉/其他/健康）。

为什么这样做：mock 默认用文件哈希随机播种（mock_source="hash"），
随机结果无法稳定触发"水质恶化 + 细菌性病害"这类多源协同规则，
Agent 的核心增量就演示不出来。

该参数默认关闭，且真实 YOLO 推理成功时代码路径**根本不会读文件名**
（见 fish_disease.py 的 hint_used 分支）。它只用于模型训练完成前的链路联调，
不用于任何准确率评测。
==============================================================================
