==============================================================================
一、OpenAPI 端点清单（GET /openapi.json）
==============================================================================

POST   /api/v1/assess    []
       摘要：融合评估（水质 + 鱼体图片 → 风险等级 / 告警 / 养殖建议）
       请求体(application/json)：AssessRequest
       响应 200：Successful Response -> AssessResponse
       响应 422：Validation Error -> HTTPValidationError

POST   /api/v1/chat    []
       摘要：知识库问答（RAG）
       请求体(application/json)：ChatRequest
       响应 200：Successful Response -> ChatResponse
       响应 422：Validation Error -> HTTPValidationError

GET    /api/v1/config/templates    []
       摘要：内置水质模板目录（用户无需自备数据即可跑通）
       响应 200：Successful Response -> TemplateCatalogResponse

GET    /api/v1/config/templates/{key}/csv    []
       摘要：下载指定内置模板的 CSV（可直接上传 / 粘贴 / 用 Excel 打开）
       路径/查询参数：key (path, 必填)
       响应 200：Successful Response -> ?
       响应 422：Validation Error -> HTTPValidationError

GET    /api/v1/config/thresholds    []
       摘要：阈值、权重与红线规则（供前端展示判定依据）
       响应 200：Successful Response -> ThresholdResponse

GET    /api/v1/config/tools    []
       摘要：工具契约（OpenAI function calling 原生格式）
       响应 200：Successful Response -> ToolSchemasResponse

GET    /api/v1/health    []
       摘要：健康检查
       响应 200：Successful Response -> HealthResponse

POST   /api/v1/ingest/image    []
       摘要：上传鱼体图片并立即识别
       请求体(multipart/form-data)：Body_ingest_image_api_v1_ingest_image_post
       响应 200：Successful Response -> IngestImageResponse
       响应 422：Validation Error -> HTTPValidationError

POST   /api/v1/ingest/sensor    []
       摘要：追加传感器读数到会话缓冲（内存态）
       请求体(application/json)：IngestSensorRequest
       响应 200：Successful Response -> IngestSensorResponse
       响应 422：Validation Error -> HTTPValidationError

GET    /api/v1/ponds/{pond_id}/history    []
       摘要：评估历史（内存态，进程重启即失效）
       路径/查询参数：pond_id (path, 必填)
       路径/查询参数：limit (query, 可选)
       响应 200：Successful Response -> HistoryResponse
       响应 422：Validation Error -> HTTPValidationError

GET    /api/v1/ponds/{pond_id}/readings    []
       摘要：读取会话缓冲里的读数
       路径/查询参数：pond_id (path, 必填)
       路径/查询参数：limit (query, 可选)
       响应 200：Successful Response -> object
       响应 422：Validation Error -> HTTPValidationError

POST   /api/v1/tools/call    []
       摘要：直接调用工具（跳过 LLM 决策，便于调试与前端联调）
       请求体(application/json)：ToolCallRequest
       响应 200：Successful Response -> ToolResultResponse
       响应 422：Validation Error -> HTTPValidationError

[definitions] TOOL_SCHEMAS:
  water_risk_predict: required=['readings']
      pond_id: string — 池塘/塘口编号，用于在多塘场景下区分告警来源，例如 'POND-03'。未知时填 'unknown'。
      readings: array — 按时间升序排列的水质记录数组，至少 3 条，建议 ≥24 条（约 1 天，1 小时/条）。每条至少包含 water_te
      interval_minutes: integer — 相邻两条记录的采样间隔（分钟）。若每条记录都带 timestamp，本参数会被自动推断值覆盖。
      horizon_hours: integer — 预测窗口长度（小时），表示'未来多久内会不会出问题'。默认 72 小时（3 天）。
      species: string — 养殖品种，决定阈值分组。鲤科（草鱼/鲫鱼/鲤鱼等）、罗非鱼、虾蟹（南美白对虾/河蟹等）。不确定时用默认值 '鲤科'。
  fish_disease_detect: required=['image_path']
      image_path: string — 鱼体图片的本地绝对路径（如 'D:\\data\\fish\\gill_01.jpg'）或 http(s) 图片 URL
      conf_threshold: number — 最低置信度阈值。低于该值仍会返回结果，但会将 is_low_confidence 置为 true。
      top_k: integer — 返回概率最高的前 K 个类别，用于展示模型的犹豫程度。
