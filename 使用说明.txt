================================================================================
  ProjectFisheries 使用说明
  最后更新：2026-10-17
================================================================================

第一次用（只做一次）：双击

        一键配置环境.bat

它会自动建好运行环境、装好依赖、建好知识库。第一次要下载约 91 MB 的中文
向量模型，慢的话等几分钟，之后就不用再点它了。看到「环境已就绪」就是配完了；
重复点也安全，做过的步骤会自动跳过。

配好之后，想启动项目，双击这个文件夹里的：

        启动接口服务.bat

等几秒，浏览器会自动打开 http://127.0.0.1:8000/app/ ，那就是整个项目。
关掉那个黑色命令行窗口，服务就停了。


--------------------------------------------------------------------------------
一、这几个文件分别干什么
--------------------------------------------------------------------------------


  启动接口服务.bat    ★ 最常用。一条命令同时起两样东西：网页界面和接口。
                       页面在 http://127.0.0.1:8000/app/ ，能上传水质表格和
                       鱼的照片，点一下按钮就出完整的决策报告。答辩、演示、
                       给别人看效果，都用这个。
                       接口文档在 http://127.0.0.1:8000/docs ，能看到全部
                       12 个接口并在线试；要把结果接进别的系统就从这里连。

  一键配置环境.bat       ★ 第一次用先点这个。自动建虚拟环境、装依赖、建知识库、
                        验证依赖是否齐全，看到「环境已就绪」就好了。重复点没关系，
                        做过的步骤会自动跳过。
                        装依赖卡住（多半是网络）时，打开命令行敲：
                          python scripts\setup_env.py --mirror tsinghua
                        换成国内镜像再装一遍。
                        它还会顺手把数据集导进来（可选，最大约 1.4 GB）。
                        没有 Kaggle 账号也没关系：数据集缺失只影响 M8 评测
                        和病害图像演示，页面和接口照常能用；想补数据可以
                        让管数据的人按 README 第 3.5 节搭一个国内镜像。

                        图像模型的权重也不在安装包里：缺了会明确提示
                        「权重缺失，将启用 mock 模拟模式」，不会假装识别。
                        补的办法见 README 第 3.6 节（--fetch-weights all）。
                        鱼种识别权重同样不在包里，缺了它鱼种那一块会直接
                        隐藏（不猜品种），水质按默认品种（鲤科）判定，
                        下拉框仍可手动选。

  运行自检.bat          环境体检。会跑一遍单元测试（1274 项）+ 端到端集成测试
                       （13 项，缺权重/缺索引的会自动跳过并说明补法）+ 全部演示
                       脚本 + 检查知识库索引。答辩前点一次，全绿就放心了。
                       它不会启动服务，跑完自己就结束。

  这些文件都在同一个文件夹里，双击即可，不需要先打开命令行。


--------------------------------------------------------------------------------
二、网页界面怎么用（4 步）
--------------------------------------------------------------------------------

  第 1 步  双击 启动接口服务.bat
           第一次启动要加载知识库，等 5～15 秒。

  第 2 步  浏览器自动打开 http://127.0.0.1:8000/app/
           （如果没自动弹出来，手动把这个地址粘进浏览器）

  第 3 步  在页面左边：
            · 用上面的【内置水质模板】下拉框挑一个场景（正常塘 / 黎明前缺氧 /
              氨氮累积 / 亚硝酸盐超标 / 暴雨降温 …共 12 个），再点【用该模板填充】：
              会自动填好这个场景的 24 小时数据，并把品种切到对应档位
            · 想用自己的数据，就【上传水质时序表格】（CSV / Excel 都行），
              或者把表格内容直接粘进粘贴框
            · 想加鱼的照片，就在【鱼体图片】那里上传一张
            · 水质表格和照片，给一个就能跑，两个都给结论更准
            · 想自己改品种档位，用表格区上面的【品种】下拉框

  第 4 步  点【运行评估】，右边会依次出现：
             决策报告（等级、融合分、一句话结论、该做什么）
             告警列表（按严重程度着色）
             数据质量（读了几行、丢了几行、采样间隔）
             图像识别结果
             融合过程（两个模态各自的分数、命中了哪些等级下限）
             知识库依据（检索到了哪几段规范）
             运行轨迹（调度 → 工具 → 融合 → 建议的每一步）


--------------------------------------------------------------------------------
三、怎么停
--------------------------------------------------------------------------------

  关掉那个黑色的命令行窗口就行；或者在窗口里按 Ctrl + C。
  不占后台，不会残留进程。


--------------------------------------------------------------------------------
四、常见问题
--------------------------------------------------------------------------------

  问：双击后窗口一闪就没了？
  答：说明启动失败了。用命令行方式跑一次就能看到报错：
        cd /d <工程>
        运行自检.bat
      自检会把问题指出来。

  问：提示端口被占用 / Cannot find empty port？
  答：换个端口。不要双击，改成在文件夹地址栏输入 cmd 回车，然后：
        启动接口服务.bat 8001
      页面地址就变成 http://127.0.0.1:8001/app/ 。

  问：页面里病害识别结果看起来准不准？用的是真模型吗？
  答：看情况，程序会自己说清楚 —— 接口服务启动时会打印一行说明，演示脚本开头也会：
       · 本机有 models\yolov8-fish.pt 且装了 ultralytics → 走【真实模型】，
         标签是模型算出来的，实测留出集准确率 93.0%（见 docs\模型训练说明.md）
       · 两样缺一样 → 走【模拟兜底】，标签是按图片内容确定性生成的，
         只用来验证整条链路能跑通，**不代表精度**
      想知道当前是哪一种，看输出里的 model_version：
         yolov8-fish.pt = 真模型     mock-v0.1 = 兜底
      真实模型只认四类（健康鱼 / 烂鳃 / 细菌性出血 / 水霉），而且是整图判断，
      **不会圈出病灶位置**（手头三份公开图集一个标注框都没有，做不了定位）。
      想自己训练一份：docs\模型训练说明.md，需要 NVIDIA 显卡。

  问：没有网 / 没有显卡 / 没有大模型 API Key，能跑吗？
  答：能。会自动降级：调度和建议由确定性模拟 + 规则模板生成，报告里会标注
      "降级模式"，其余流程完全一样。只有"训练病害识别模型"这一步需要显卡，
      推理本身 CPU 也能跑（慢一些）。

  问：回译层说「离线也能把英文建议翻成中文」，可是我这边翻不出来？
  答：要单独下一个本地翻译模型（约 315 MB，不在软件包里）：
        .venv\Scripts\python.exe -m pip install -e ".[translate]"
        .venv\Scripts\python.exe scripts\fetch_translate_model.py
      下完不用配任何 Key，程序会优先用它。没有也能跑，只是超过 6 个英文词
      的长句没法翻，会退回规则模板的中文表述，并在报告里写明降级原因。
      细节见 docs\M10_回译层说明.md。

  问：想给别的电脑访问？
  答：默认只监听本机（127.0.0.1），别人连不上。要开放的话，用记事本打开
        run-api.bat
      把这一行
        set "HOST=127.0.0.1"
      改成
        set "HOST=0.0.0.0"
      保存后重新双击。启动时窗口里会打印局域网地址，别人用那个地址访问。

  问：数据集在哪？我把这个文件夹拷给别人，没有数据集能跑吗？
  答：能跑，而且工程里本来就没带数据集 —— 仓库里只有代码。
      数据集（1.37 GB）就在工程内的 data\datasets\ ，但没进 Git 仓库
      程序会自己去找，不用配任何路径。找不到的话：
        · 网页界面照样能开，「上传自己的表格」和「内置水质模板」不受影响
        · 需要数据集的那几个单元测试会显示 skipped（跳过），不是 failed（失败）
        · 个别演示脚本会打印一行「该数据集未导入」然后继续
      想看当前认得哪些数据集，在工程目录里跑：
        .venv\Scripts\python.exe scripts\fetch_datasets.py --status

        .venv\Scripts\python.exe scripts\fetch_datasets.py --weights    看权重状态
      想换位置（比如换台电脑、换块盘）：把 数据集 文件夹拷过去，然后设一个
      环境变量指过去即可，代码一行不用改：
        set FISHERIES_DATA_ROOT=E:\你放数据集的目录

  问：数据集太大了，1.37 GB 能瘦身吗？
  答：能，而且能砍掉一大半。里面最大的 archive 文件夹占 1.07 GB（2055 张
      PNG 图片），实测没有任何代码在用它，可以直接删掉。
      另外 SB-FishDisease（10.6 MB）和 Freshwater Fish Disease（24.8 MB）经
      文件名比对与 Fish Disease Dataset 是同一批照片，一张新图都没多，
      也可以整目录删掉。三份一起删完约剩 180 MB。
      详细清单见 README 第 13.1 节。

  问：命令行里跑脚本，中文变成乱码了？
  答：别用 PowerShell 的 type / Get-Content 看 .bat，也别自己 set PYTHONIOENCODING。
      脚本自己会调 fisheries/console.py 把输出的容错放宽（但不会改编码——改了反而
      是乱码的来源）。如果确实看到乱码，最省事的办法是在命令行先敲一次：
          chcp 65001
      双击 .bat 启动的那几个入口本来就已经替你做了这一步。

  问：.bat 文件打开看全是英文，是没做汉化吗？
  答：是故意的。cmd.exe 解析批处理文件时按控制台代码页分块解码，文件里只要出现一个
      中文字符，后面的行就可能被从中间切开当成命令执行，黑窗口里于是多出一串
          'x' is not recognized as an internal or external command
      这种噪声（而且退出码还是 0、服务照常起来，很容易漏掉）。所以：
          - 中文名的 启动接口服务.bat / 运行自检.bat 只负责转发；
          - 真正的逻辑在同目录的 run-api.bat / run-selftest.bat，
            这两个是纯 ASCII，一个非 ASCII 字节都没有；
          - 你看到的全部中文提示，都是 Python 打印的（src\fisheries\launcher.py
            与 scripts\selftest.py）。
      双击的时候中文显示完全正常，看到 .bat 里面是英文不用管。

五、命令行方式（等价，适合排查问题）
--------------------------------------------------------------------------------

  打开命令行后先准备环境（每次新开窗口都要做一次）：

      cd /d <工程>
      set PYTHONPATH=<工程>\src
      set PYTHONIOENCODING=utf-8

  接口服务 + 网页界面（同一个进程，页面在 /app/ ）：

      .venv\Scripts\python.exe -m fisheries.api

  全部单元测试（1274 项，约 6 分钟）：

      .venv\Scripts\python.exe -m pytest tests/unit -o addopts="" -q

  端到端集成测试（13 项，10 秒；真模型 + 真知识库，缺料自动跳过）：

      .venv\Scripts\python.exe -m pytest tests/integration -o addopts="" -q

  随机挑一个离线演示脚本看效果（不占端口，直接打印）：

      .venv\Scripts\python.exe scripts\demo_agent.py      完整推理链路
      .venv\Scripts\python.exe scripts\demo_cases.py      6 组边界案例
      .venv\Scripts\python.exe scripts\demo_translate.py  中英回译层

  数据集体检（看程序认到了哪些数据集、都在哪个路径）：

      .venv\Scripts\python.exe scripts\fetch_datasets.py --status

  模型权重：看状态 / 补下载（三个约 13 MB，下载完自动核 md5）：

      .venv\Scripts\python.exe scripts\fetch_datasets.py --weights
      .venv\Scripts\python.exe scripts\fetch_datasets.py --fetch-weights all

  想重新训练病害识别模型（需要 NVIDIA 显卡，约 20 分钟）：

      .venv\Scripts\python.exe scripts\train_yolo_fish.py --report   先体检
      .venv\Scripts\python.exe scripts\train_yolo_fish.py            正式训练
      训练完权重写到 models\yolov8-fish.pt，图像模态自动切到真实模型。

  想重新训练鱼种三档分类模型（鲤科 / 罗非鱼 / 虾蟹，需要显卡，约 10 分钟）：

      .venv\Scripts\python.exe scripts\train_yolo_species.py --check   先看数据
      .venv\Scripts\python.exe scripts\train_yolo_species.py           正式训练
      训练完权重写到 models\yolov8-species.pt，鱼种那一块自动出现在页面上。

六、东西都在哪
--------------------------------------------------------------------------------

  <工程>\
      启动接口服务.bat          ← 双击这个（转发到 run-api.bat，同时托管网页）
      运行自检.bat                 转发到 run-selftest.bat
      一键配置环境.bat             转发到 setup.bat（第一次用先双击它）
      setup.bat                ↑ 这四个是实际逻辑，纯 ASCII，别改出中文来
      run-api.bat
      run-selftest.bat
      使用说明.txt             本文件
      README.md               项目全貌：做了什么、怎么设计的、怎么验收的
      docs\项目说明及流程.txt  项目背景、选题、开发流程的说明材料
      web\                    网页界面本身（纯原生 HTML/CSS/JS，不需要编译）
      examples\pond_demo_water.csv   示例水质表格
      templates\                    12 个内置水质场景模板（页面下拉框用的就是它们）
      scripts\fetch_datasets.py      数据集体检/下载工具（--status 看认到哪些）
      scripts\fetch_translate_model.py  下本地翻译模型（约 315 MB，可选）
      scripts\train_yolo_fish.py     训练病害识别模型（可选，需显卡）
      src\fisheries\datasets.py      「数据集名字 → 磁盘位置」的唯一定义处
      models\yolov8-fish.pt          训练好的病害识别权重（约 3 MB；有这个才走真模型）
      models\yolov8-species.pt       鱼种三档分类权重（约 3 MB；缺了鱼种块就隐藏）
      scripts\train_yolo_species.py  训练鱼种分类模型（可选，需显卡）
      models\checksums.md5           权重校验值（md5），跟着仓库走，随时能核
      models\translate\              本地离线翻译模型（有这个就不必配翻译 Key）
      data\datasets\                 原始数据集（1.37 GB，28,794 文件，不进 Git）
      data\derived\                  训练/评测用的派生数据（22.6 MB，可重建可删）
      data\uploads\api_state.sqlite3  会话数据（读数缓冲 / 评估历史，按浏览器隔离，重启不丢）
      docs\
          技术方案设计.md         完整设计文档
          数据集说明.md           用的哪些公开数据集、为什么用、有什么坑
          模型训练说明.md         病害识别模型怎么训、指标多少、怎么复现
          demo_cases_output.txt   6 组边界案例的完整推理输出
          demo_*.txt              各个演示脚本的输出存档
          M8_评测报告.md          两组外部验证的结果（含失败分析）+ 图像模态一节
          M10_回译层说明.md       回译层：模型下载、分块限长、术语后订正、已知限制

  data\datasets\（原始数据集，不进 Git 仓库，只在本机）
      1.37 GB / 28,794 文件，程序会自动找到，不用配路径。
      最大的 archive\ 子目录（1.07 GB）没有任何代码在用，可以放心删掉瘦身；
      SB-FishDisease\ 与 Freshwater Fish Disease…\ 跟 Fish Disease Dataset 是
      同一批照片（去重后一共只有 931 张不同图），也可以删。

  Web 界面源码就在工程内的 web\ 目录
      纯原生 HTML/CSS/JS，没有构建步骤、没有 CDN，改完刷新页面就生效：
          index.html              页面骨架
          css\app.css             全部样式
          js\app.js               四个页面的路由与交互
          js\api.js               接口客户端（12 个端点）
          js\parse.js             表格解析（CSV / TSV / Excel / 粘贴文本）
          js\dict.js              枚举字典（规则码 / 红线 / 病害标签的中文翻译）
          js\ui.js                报告渲染
          js\charts.js            零依赖 SVG 图表
          js\markdown.js          Markdown 渲染
      页面由接口进程同源托管在 /app ，不需要单独起前端服务。

七、出问题找谁

  如果自检全绿但页面不对劲，把命令行窗口里的报错文字截图发出来。
