# 水产养殖AI Agent应用｜完整项目实现方案（适配第二届全国人工智能应用创新大赛·高职组）
> 项目定位：**水产养殖智能监测与决策Agent**
核心业务：采集水质（水温、pH、溶氧、氨氮、亚硝酸盐）、养殖密度、投料记录、病害图片；
Agent自动完成：数据清洗→水质风险预测→病害图像识别→生成养殖建议告警，辅助养殖户。

技术栈：`pandas/numpy/scikit-learn/TensorFlow`、`matplotlib`、`Label Studio`标注，最后封装Agent调用模型做对话式问答。

> 大赛优势：属于**乡村振兴+智慧农业**赛道，是上一届国赛高频获奖方向；高职组不要求底层自研大模型，重点看**工程落地、完整工作流、场景价值**。

## 一、项目整体架构
四层结构（申报书可以直接画这个框图）
1. **数据层**：水质时序表格数据 + 水产病害图片数据集（LabelStudio标注）
2. **预处理层**：Pandas清洗，Numpy标准化，Matplotlib可视化探索
3. **模型层**
    - 时序预测模型（TensorFlow）：预测溶氧/氨氮未来变化，预警水质恶化
    - 图像分类/检测模型（TensorFlow）：识别鱼体病害（烂鳃、出血、水霉）
4. **Agent应用层**：智能体串联模型，接收养殖户输入（文字/图片），调用预测模型，输出养殖方案、告警、建议。Agent可封装网页端做交互演示。

---
1. 水产病害图像数据集：采用开源 SB-FishDisease 淡水鱼病害数据集，包含烂鳃病、细菌性出血败血症、水霉病、健康鱼等类别，原始图像 1700 余张，采用翻转、亮度扰动、水体噪声模拟等数据增强方法扩充样本，用于 Agent 内鱼体病害图像识别模型训练。
2. 水质时序数据集：使用 PondsData 池塘 IoT 传感器时序数据集，采集水温、pH、溶解氧、氨氮等长期连续监测数据，构建时序样本，用于水质趋势预测、水质恶化风险判别；结合水产行业标准阈值生成风险告警标签。
数据集遵循 CC 开源协议，合规用于本创新大赛项目。

# 二、完整项目实施流程（按比赛时间线划分，适合大二团队）
## 阶段1：需求调研 & 方案设计（1～2周，文档负责人主攻）
### 1.1 业务需求
目标用户：鱼塘养殖户
解决痛点：
- 人工记录水质麻烦，无法预判水质突变（缺氧翻塘是重大损失）
- 新手养殖户不会识别鱼病，延误治疗
Agent能力：
① 上传水质记录表，自动分析水质，预测未来3天指标变化，风险告警
② 上传鱼照片，识别病害，给出用药/调水方案
③ 对话问答：养殖户提问，Agent查询历史养殖数据，给出个性化建议

### 1.2 数据集规划
两类数据：
1. **结构化表格数据（时序）**
    字段：日期、水温、pH、溶解氧DO、氨氮、亚硝酸盐、养殖密度、投料量、是否发病
    来源：公开水产数据集 + 模拟采集数据（比赛不需要实地采集真实鱼塘数据，公开数据集完全够用）
2. **图像数据集（病害图片）**
    淡水鱼健康/烂鳃、水霉、赤皮、出血等图片，用**Label Studio标注**

## 阶段3：结构化数据处理（Pandas+Numpy+Matplotlib）【核心代码环节】
### 3.1 数据清洗（pandas）
处理缺失值、异常值（传感器故障产生离谱数值）、重复行
```python
import pandas as pd
# 读取水产水质csv
df = pd.read_csv("aquaculture_water.csv")
# 缺失值填充
df['DO'] = df['DO'].fillna(df['DO'].mean())
# 剔除异常值（例如溶氧>20为传感器错误）
df = df[(df["DO"]>0) & (df["DO"]<20)]
```
### 3.2 数据标准化（numpy + scikit-learn）
水质指标量纲不一样，做标准化，用于训练预测模型
```python
import numpy as np
from sklearn.preprocessing import StandardScaler
feature_cols = ["temp","pH","DO","ammonia"]
scaler = StandardScaler()
df[feature_cols] = scaler.fit_transform(df[feature_cols])
```
### 3.3 数据可视化（matplotlib.pyplot）

## 阶段4：模型搭建训练（TensorFlow）
两个模型，轻量化，普通电脑就能训练，不需要GPU
1. **水质时序预测模型（LSTM）**
    输入历史7天水质数据，预测未来3天的溶氧、氨氮；当预测值超过安全阈值，触发告警。
    TensorFlow搭建LSTM时序网络。
2. **鱼病图像分类模型**
    加载LabelStudio标注好的图片数据集，用TensorFlow搭建轻量CNN模型（MobileNet迁移学习，**推荐！**，训练快，效果好）
    输入鱼照片，输出病害类别+置信度。

> ✅重点：高职比赛，**迁移学习完全允许**，不需要从零训练CNN底层。

## 阶段5：构建水产养殖AI Agent（项目创新核心，拿高分关键点）
> Agent作用：串联上面两个模型，形成智能体。不是单纯调用一个大模型，是**工具调用型Agent**。
Agent工作流程：
1. 用户输入（文字提问 / 上传鱼图片 / 上传水质表格）
2. Agent判断任务类型：
    - 如果上传图片 → 调用TensorFlow鱼病识别模型
    - 如果上传水质表格 → 调用LSTM水质预测模型
    - 如果文字提问 → 检索知识库（水产养殖文档），结合模型结果生成回答
3. 整合模型输出，用LLM API（DeepSeek/通义千问）整理成通俗易懂的养殖建议、风险告警
4. 返回结果给用户（网页或者QQ机器人界面）

Agent逻辑伪代码：
```
用户输入
if 输入包含图片:
    调用鱼病识别模型 → 获取病害
    大模型生成病害处理方案
elif 用户上传水质数据:
    pandas读取数据，预处理，LSTM预测水质
    判断是否超过安全阈值，生成风险告警
else:
    RAG检索水产知识库，回答养殖问题
输出完整报告
```

# 阶段5：构建水产养殖AI Agent（项目创新核心，大赛高分重点）
> 核心思路：**工具调用型智能体**，Agent作为调度中枢，自动判断用户输入类型，选择调用LSTM水质预测模型 / 鱼病图像识别模型，再结合大模型LLM生成通俗易懂的养殖建议、风险告警，不是单纯的对话聊天机器人。

## 5.1 Agent核心能力定义
1. **输入识别**：接收三类输入：水质CSV表格、鱼体图片、养殖户自然语言文字提问
2. **工具路由调度**
    - 上传水质时序表格 → 触发【水质预测工具】：执行pandas数据清洗→标准化→LSTM预测，判断溶氧、氨氮是否超出安全阈值，生成水质风险告警
    - 上传鱼照片 → 触发【鱼病识别工具】：调用MobileNet图像分类模型，输出病害类型+置信度
    - 纯文字提问 → 触发【RAG知识库检索工具】，检索水产知识库，结合历史养殖数据回答问题
3. **结果整合**：将模型输出的冰冷数值、病害类别，交给LLM（DeepSeek/通义千问API）转化为养殖户看得懂的自然语言方案，包含调水操作、用药建议、注意事项
4. **输出返回**：生成完整分析报告、告警提示，在Web页面/QQ机器人展示

## 5.2 Agent执行逻辑流程图（PPT可以直接画）
```
养殖户输入（图片/CSV/文字）
        ↓
【Agent意图判断模块】
├─如果是水质CSV文件 → 水质预测工具流水线
│     ├─pandas读取csv → 清洗异常、缺失数据
│     ├─numpy+sklearn标准化
│     ├─LSTM模型预测未来3天水质指标
│     └─阈值判断，输出风险等级（安全/预警/高危）
├─如果是图片 → 鱼病识别工具流水线
│     ├─图片预处理（缩放、归一化）
│     ├─MobileNet模型推理
│     └─输出病害名称、置信度
└─纯文本问答 → RAG检索知识库
        └─检索本地水产养殖文档资料
        ↓
【LLM结果整合模块】
把模型结果、知识库信息，生成自然语言：告警+解决方案
        ↓

```

## 5.3 Agent伪代码（可写入项目报告，也可基于此开发Python代码）
```python
# 水产养殖AI Agent主调度逻辑
class AquacultureAgent:
    def __init__(self, lstm_model, cnn_model, llm_api):
        self.lstm_model = lstm_model       # LSTM水质预测模型
        self.cnn_model = cnn_model         # 鱼病图像分类模型
        self.llm = llm_api                 # 大模型API，用来生成文本建议

    def run(self, user_input, input_type):
        # input_type: "water_csv" / "fish_image" / "text_question"
        if input_type == "water_csv":
            # 水质时序预测分支
            df = pd.read_csv(user_input)
            df_clean = data_clean(df)                # pandas清洗
            data_scaled = data_standard(df_clean)    # numpy+sklearn标准化
            pred_result = self.lstm_model.predict(data_scaled)
            risk_info = judge_water_risk(pred_result)
            prompt = f"基于水质预测结果{pred_result},{risk_info}，给养殖户撰写调水方案"

        elif input_type == "fish_image":
            # 鱼病识别分支
            img_tensor = preprocess_image(user_input)
            disease, confidence = self.cnn_model.predict(img_tensor)
            prompt = f"识别到鱼病：{disease}，置信度{confidence:.2f}，请给出治疗方案与注意事项"

        elif input_type == "text_question":
            # 文本问答RAG分支
            knowledge = rag_search(user_input)
            prompt = f"参考养殖知识库：{knowledge}，回答养殖户问题：{user_input}"

        # 调用大模型，生成最终回复
        final_report = self.llm.chat(prompt)
        return final_report
```
